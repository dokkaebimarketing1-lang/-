# AI 뮤직비디오 마켓플레이스

AI 기술을 활용하여 뮤직비디오를 제작하는 프리랜서 크리에이터들이 활동하는 재능마켓 플랫폼입니다.

## 🎯 주요 기능

### 1. 크리에이터 갤러리
- 다양한 전문 분야의 AI 뮤직비디오 크리에이터 소개
- 포트폴리오 영상 미리보기
- 평점, 리뷰, 완료 건수 등 신뢰도 정보 표시
- 실시간 검색 및 필터링 기능

### 2. 프리랜서 프로필 페이지
- 크리에이터 상세 정보 및 전문 기술
- 포트폴리오 영상 갤러리 (클릭하여 재생 가능)
- 전화 상담 기능 (전화번호 표시 및 원클릭 통화)
- 가격 정보 및 서비스 안내

### 3. 주문 의뢰 시스템
- 직관적인 주문 폼
- 프로젝트 상세 정보 입력
- 음악 장르, 예산, 일정 선택
- 참고 자료 및 음악 파일 URL 첨부 가능

### 4. 카테고리 시스템
- 힙합/랩
- 발라드/감성
- EDM/일렉트로닉
- K-POP
- 애니메이션
- 시네마틱

## 🛠 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: Node.js, Express.js
- **UI/UX**: Font Awesome Icons, 반응형 디자인
- **데이터**: JSON 기반 데이터 관리

## 📁 프로젝트 구조

```
webapp/
├── server.js                 # Express 서버
├── package.json             # 프로젝트 설정
├── data/
│   └── freelancers.json     # 프리랜서 데이터
└── public/
    ├── index.html           # 메인 페이지
    ├── freelancer.html      # 프리랜서 상세 페이지
    ├── order.html           # 주문 페이지
    ├── css/
    │   ├── style.css        # 메인 스타일
    │   ├── freelancer.css   # 프로필 페이지 스타일
    │   └── order.css        # 주문 페이지 스타일
    └── js/
        ├── main.js          # 메인 페이지 로직
        ├── freelancer.js    # 프로필 페이지 로직
        └── order.js         # 주문 페이지 로직
```

## 🚀 실행 방법

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm start
```

서버가 `http://localhost:3000`에서 실행됩니다.

## 📱 주요 페이지

### 1. 홈페이지 (`/`)
- 히어로 섹션: 검색 기능 및 서비스 소개
- 인기 카테고리 둘러보기
- 추천 크리에이터 목록
- 이용방법 안내

### 2. 프리랜서 프로필 (`/freelancer/:id`)
- 크리에이터 소개 및 전문 분야
- 포트폴리오 영상 갤러리
- 전화 상담 버튼
- 주문하기 버튼

### 3. 주문 페이지 (`/order/:id`)
- 의뢰인 정보 입력
- 프로젝트 상세 정보
- 예산 및 일정 선택
- 요구사항 작성

## 🎨 디자인 특징

### 크몽 스타일 UI/UX
- 직관적이고 깔끔한 카드 레이아웃
- 신뢰감을 주는 색상 체계 (초록색 강조)
- 반응형 디자인으로 모바일 최적화
- 부드러운 애니메이션 효과

- Primary: `#00c471` (초록)
- Secondary: `#ff6b6b` (빨강)

- Light Background: `#f8f9fa`

## 📊 샘플 데이터

6명의 프리랜서 크리에이터 프로필 포함:
1. 김아트 - 힙합/랩 전문
2. 이크리에이터 - 발라드/감성 전문
3. 박비주얼 - EDM/일렉트로닉 전문
4. 정뮤직 - K-POP 전문
5. 최애니메이션 - 애니메이션 전문
6. 강시네마 - 시네마틱 전문

## 🔌 API 엔드포인트

### GET `/api/freelancers`
모든 프리랜서 목록 조회

### GET `/api/freelancers/:id`
특정 프리랜서 정보 조회

### POST `/api/order`
주문 접수
- Request Body: 주문 정보 (JSON)
- Response: 성공/실패 메시지

## ✨ 주요 기능 상세

### 검색 및 필터링
- 이름, 전문 분야, 기술로 실시간 검색
- 평점순, 주문순, 리뷰순 정렬
- 카테고리별 필터링

### 전화 상담
- 버튼 클릭으로 전화번호 표시
- 모바일에서 원클릭 통화 지원

### 포트폴리오 영상
- 모달 팝업으로 영상 재생
- 유튜브 임베드 지원
- 조회수 표시

### 주문 폼 유효성 검사
- 필수 항목 체크
- 이메일/전화번호 형식 검증
- 전화번호 자동 포맷팅
- 날짜 선택 제한 (오늘 이후만)

## 🔧 커스터마이징

### 프리랜서 추가
`data/freelancers.json` 파일에 새로운 프리랜서 정보를 추가하세요.

### 스타일 변경
- `public/css/style.css`: 전역 스타일 및 메인 페이지
- `public/css/freelancer.css`: 프로필 페이지
- `public/css/order.css`: 주문 페이지

### 카테고리 수정
`public/index.html`의 카테고리 섹션을 수정하고, `public/js/main.js`의 필터링 로직을 조정하세요.
